Este es el diagrama de clases del motor de busquedad que se implementara, tiene 3 principales componentes, el de rastreo de la información, el de indexación de la información, y el de clasificación de la información. El componente de rastreo tiene bots de rastreo la idea es automatizarlos, se piensa que para garantizar una rapida y eficiente busqueda, que cada bot realize una busqueda en un hilo especifico. Adicional a esto se tiene pensado implementar un arbol de huffman con palabras para acceder mas facil a la información mas frecuente.

El diagrama ira cambiando conforme se vaya desarrollando el proyecto.
