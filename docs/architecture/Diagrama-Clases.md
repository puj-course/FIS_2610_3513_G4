# Diagrama de Clases de las 3 Funcionalidades más Importantes

Se destacan las clases agrupadas en los siguientes paquetes:

- Auth: Lógica de registro e inicio de sesión de todo tipo de usuarios.
- Brand: Lógica de Marcas, agregación y gestión de productos propios.
- Product: Lógica de productos y su registro en la base de datos.
- Enums: Enumeradores para los detalles de los productos.
